# Analyzing-Selling-Price-of-used-Cars-using-Python
This project focuses on analyzing factors that influence the selling price of used cars using Python-based data analysis techniques. The dataset contains automobile specifications such as engine size, fuel type, body style, mileage, and other technical attributes.
The project involves data cleaning, preprocessing, exploratory data analysis, and visualization to identify patterns affecting car prices. Statistical analysis and visual tools were used to understand relationships between features and vehicle price, helping uncover insights useful for pricing strategies and market understanding.

Key findings show that engine size, drive type, vehicle body style, and fuel efficiency significantly impact used car prices.

🛠 Tools & Technologies Used

Python

Pandas & NumPy

Matplotlib & Seaborn

SciPy

Jupyter Notebook / Google Colab

📊 Key Steps Performed

Dataset loading and preprocessing

Handling missing and inconsistent values

Data normalization and transformation

Price binning and feature grouping

Exploratory Data Analysis (EDA)

Visualization using boxplots, scatter plots, histograms

Statistical analysis (ANOVA)

Feature relationship analysis

🎯 Outcome

The project demonstrates how data analysis techniques can be applied to determine key factors affecting used car pricing and supports data-driven decision-making in automobile sales.
